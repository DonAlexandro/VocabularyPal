# Story Template

Use this template when writing a story file to `docs/stories/{story-name}.md`.

```markdown
# {Feature Name}

## Description

**As a** [specific user role — e.g. lab operator, scientist, service technician]

**I want to** [concrete action or capability]

**So that** [the value or outcome achieved]

---

## Acceptance criteria 1: [short title]

Given: [starting context / precondition]

When: [user action or system event]

And: [additional condition — remove this line if not needed]

Then: [observable outcome]

---

## Acceptance criteria 2: [short title]

Given: [starting context / precondition]

When: [user action or system event]

Then: [observable outcome]

---

<!-- Add further criteria blocks as needed. Number them sequentially. -->
```
